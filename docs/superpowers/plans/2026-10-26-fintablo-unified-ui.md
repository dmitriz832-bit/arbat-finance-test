# Unified Fintablo UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development task by task.

**Goal:** Единые визуальные и поведенческие компоненты во всем действующем приложении.
**Architecture:** Централизованные токены, базовые контролы/типографика, общий слой модальных окон, асинхронные подтверждения и сообщения, согласованная визуализация графиков. Структурные старые стили сохраняются, декоративные конфликты устраняются.
**Tech Stack:** Статический JS/CSS, Source Sans Pro, существующее финансовое ядро и CAS, node:test/Playwright.
**Spec:** docs/superpowers/specs/2026-10-26-fintablo-ui-system-design.md

## Constraints

- Не менять финансовые суммы, привязки, форматы документов и защиту периодов.
- confirm переводить на await в каждом обработчике; Promise не используется как boolean.
- На375px нет горизонтального скролла страницы; таблицы могут иметь отдельный viewport.
- Все источники данных для проверок синтетические; личные экранные данные не публикуются.
