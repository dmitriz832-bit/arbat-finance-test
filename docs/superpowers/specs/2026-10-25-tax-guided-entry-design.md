# Упрощение налогового ввода

Одобрено пользователем «Делай» после предложения «одна операция — один ввод».

Обычный сотрудник сохраняет хозяйственный документ; неподтверждённые налоги не мешают сохранению. Бухгалтер видит статус и предложение из уже введённых реквизитов, подтверждает условия одним действием. Полный ручной редактор остаётся для исключений и исторических данных. Частичное признание раскрывается отдельно.

Для расходов предложение содержит дату операции, допустимую сумму (без принимаемого к вычету НДС, для зарплаты со взносами), существующее основание. Подтверждение не происходит при открытии или изменении формы. Основание платежа само по себе не означает получение товара: для ДДС основание признания вводится отдельно. Изменение суммы, ставки, организации или даты обновляет предложение, но не переписывает подтверждённые поля.

В регистрах выбор исходного документа предлагает дату и доступный остаток; организация наследуется при открытии из карточки. Ставка берётся только из явных реквизитов источника, не из календаря или режима по умолчанию. УПД можно использовать как основание вычета только после подтверждения условий пользователем. Сверка обязательств и ЕНС сохраняют независимое документальное подтверждение.

Подходы: только скрыть поля (не устраняет дублирование); полностью автоматическое признание (недостаточно оснований); подготовка данных с явным подтверждением (выбранный вариант). Существующие расчёты, форматы данных, CAS, серверные ограничения и закрытие периодов сохраняются. Светлый адаптивный интерфейс без цветных подложек цифр.
